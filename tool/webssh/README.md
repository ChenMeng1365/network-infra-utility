# WebSSH

这是一个WebSSH接口，用来在本地转发SSH客户端，开箱即用。

下载之后配置`config.yml`，设置好登录用户名和口令，`process_name`填写需要监控的进程名称，然后就会转发会话进程，Web和CLI均可用。

## 页面功能

- **会话管理**：进程端口自动探测、手动端口连接、后端独立会话（页面刷新/关闭不丢会话，可重新接入）、历史日志查看/下载
- **空闲保活**：连接后 60 秒无任何输入，自动向远端发送一个空格、3 秒后发送一个退格（擦除空格），防止设备空闲超时断开
- **CJK 对齐**：全角字符（汉字、中文标点、全角符号）按 2 列宽度渲染与计数，光标严格对齐到字符之后
- **命令发送**：选择目标会话或群体发送，多行命令按设定间隔逐行下发；点击发送后焦点自动回到输入框，不会误触按钮
- **文件夹**：SFTP 远程目录浏览；点击文件可多选，"下载选中"串行下载（分块流式回传，带进度条）；拖拽文件到主区域上传；上传限速为 16 档阶梯滑块（不限速 / 1K ~ 50M）
- **工具栏**：config.yml 中 `toolbar.groups` 配置的快捷命令按钮，以及 `extension/*.md` 解析出的扩展工具栏；按钮始终可点（无会话时点击会提示），发送后焦点自动切回终端

## 扩展工具栏（Markdown）

`extension/` 目录下每个 `.md` 文件是一组扩展工具栏：

- 文件名 = 工具栏名称；`#`~`######` 标题 = 分组/按钮（按层级嵌套）
- ```shell 代码块 = 绑定到最近标题的命令脚本（多行按 `toolbar.line_delay` 间隔下发）
- 标题与代码块之间的文本 = 按钮提示（tooltip）

也可以在"工具栏"页直接点 **导入工具栏 (.md)** 临时上传（保存到服务器 `extension/` 目录并立即生效），或点 **刷新工具栏** 重新加载，无需刷新页面。

## 配置说明

参考 `config.yml.template`。要点：

- `ssh.process_name`：进程名（单个字符串或列表），自动探测监听端口；留空则用 `ssh.port` 手动端口
- `web.port`：Web 服务端口
- `toolbar.line_delay`：多行脚本每行发送间隔（秒）
- `logs.*`：会话日志自动保存与逐步交互日志

## 运行

```
pip install -r requirements.txt
python app.py
```

浏览器打开 `http://127.0.0.1:<web.port>`，或用 `web.bat` 启动。
