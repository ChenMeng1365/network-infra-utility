# 设备诊断工具集

常用网络设备诊断命令集合，点击按钮直接发送到当前终端会话。

## 辅助功能

### 全量显示

批量命令时不设分页，完全显示所有命令

```shell
screen-length 0 temporary
```

## 基础查看

### 查看版本

查看设备软件版本信息

```shell
display version
```

### 查看当前配置

显示当前运行的完整配置

```shell
display current-configuration
```

### 查看接口状态

```shell
display interface brief
```

## 网络诊断

### Ping 测试

向目标地址发送 5 个 ICMP 包

```shell
ping -c 5 192.168.1.1
```

### 查看路由表

```shell
display ip routing-table
```

### 查看ARP表

```shell
display arp
```

## 性能监控

### CPU 使用率

查看设备 CPU 使用情况

```shell
display cpu-usage
```

### 内存使用

```shell
display memory
```

### 接口流量统计

```shell
display interface counters rate
```

## 系统管理

### 查看告警

```shell
display alarm active
```

### 保存配置

```shell
save force
```

### 查看日志

显示最近的系统日志信息

```shell
display logbuffer
```
